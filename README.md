# the-first-question

AIと人間が共存していく社会が、日々変化しつつあります。

## AIの役割は何でしょう？

人間とは何かについてさえ、ヒトはまだ一つの答えを持っていません。

**そんな中、人間とAIの関係性を、今、誰と誰が、誰とどのように考えているのでしょうか？**

パソコンや携帯電話がアップグレードしていくスピードに、ヒトは追いついているのでしょうか？

**ましてや、AIには？**

**そもそも、こんな問いを立てて、ヒトとヒト、ヒトとAI、AIとAIが議論を深められるのでしょうか？**

**同意も反論も、みなさんはどう考えますか？**

**それが、この問いの始まりです。**
